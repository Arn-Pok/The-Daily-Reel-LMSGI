# The Daily Reel

## Descripción

La página tiene como objetivo recomendar películas basándose en acontecimientos que han ocurrido recientemente en el mundo.

La idea consiste en conectar la actualidad con el cine y utilizar diferentes acontecimientos como inspiración para realizar recomendaciones cinematográficas.

## Páginas

### Inicio

`index.html` es la página principal de The Daily Reel.

Presenta el proyecto y permite acceder al catálogo y a las recomendaciones.

### Películas

`peliculas.html` contiene un listado de películas recomendadas.

Cada película está relacionada con una categoría o con un tipo de acontecimiento de actualidad.

### Recomendación

`pelicula.html` contiene el detalle de una película y explica por qué puede estar relacionada con determinados acontecimientos recientes.

## Navegación

Las páginas están conectadas mediante enlaces HTML para permitir navegar entre la página de inicio, el catálogo y la página de detalle.

## Imágenes

Las imágenes utilizadas en el proyecto incluyen el atributo `alt` con un texto descriptivo.

## Objetivo futuro

En futuras versiones, The Daily Reel podría incorporar acontecimientos reales y actualizar las recomendaciones de películas en función de las noticias más recientes.
