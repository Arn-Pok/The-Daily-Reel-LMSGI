
# Decisiones del proyecto - The Daily Reel

## Proyecto
Página web sobre la película Interstellar.

## Imágenes responsive

He decidido utilizar el elemento HTML5 picture
para adaptar las imágenes a diferentes dispositivos.

He preparado tres resoluciones:

- 480x360: móviles.
- 768x576: tablets.
- 1920x1440: ordenadores.

## Accesibilidad

He añadido el atributo alt a la imagen para
que las personas que no puedan visualizarla
puedan conocer su contenido mediante una
descripción alternativa.

## Metadatos

He utilizado JSON-LD con el tipo Article
porque la página presenta información y
contenido descriptivo sobre una película.

También he añadido información sobre la película
mediante el tipo Movie.

## Diseño responsive

He mantenido la estructura original de
The Daily Reel y he añadido reglas CSS
para adaptar la imagen a diferentes pantallas.

## Herramientas

- Visual Studio Code.
- Google Chrome.
- DevTools.
- ImageMagick.
- Schema.org Validator.

## Conclusión

El objetivo es mejorar la accesibilidad,
el rendimiento y la adaptación de la página
a diferentes dispositivos.
